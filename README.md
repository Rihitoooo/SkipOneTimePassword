# SkipOneTimePassword

京都大学の認証システム（Kyoto University Authentication System）において、**メールによる多要素認証を利用する際に、ワンタイムパスワード（OTP）を自動入力するChrome拡張機能**です。

## 拡張機能の説明

京都大学の認証システムでは、多要素認証の方法として複数の方式が用意されています。

本拡張機能は、そのうち **メールでワンタイムパスワード（OTP）を受け取る方式にのみ対応しています。**

Gmailから最新のOTPを自動で取得し、京都大学の認証ページに入力することで、認証のたびにGmailを開いてOTPをコピー＆ペーストする手間を省きます。

> **注意:** 認証アプリなど、メール以外の多要素認証方式には対応していません。

## 拡張機能の使い方

### 1. デベロッパーモードを有効にする

Chromeで `chrome://extensions` を開き、右上の **「デベロッパーモード」** をオンにしてください。

### 2. 拡張機能を読み込む

**「パッケージ化されていない拡張機能を読み込む」** を選択し、ダウンロードした拡張機能のファイル（フォルダ）を選択してください。

### 3. 京都大学の認証ページにアクセスする

メールによる多要素認証を選択した状態で京都大学の認証ページにアクセスすると、OTPの取得・入力が自動的に行われます。

初回使用時には、OTPを取得するために **Googleアカウントによる認証とGmailへのアクセス許可** が必要です。

## 注意事項

* 本拡張機能は、**メールによる多要素認証を利用する場合のみ使用できます。**
* 認証アプリなど、メール以外の多要素認証方式には対応していません。
* OTPを取得するため、Gmailへのアクセス許可が必要です。
* 本拡張機能は京都大学の認証システムを利用するユーザーを対象としています。
* 拡張機能の利用・管理は自己責任で行ってください。
